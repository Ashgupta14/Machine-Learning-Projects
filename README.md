# Machine Learning Projects

A collection of machine learning projects built while learning data science and machine learning concepts. Each project includes a notebook, documentation, and evaluation results where available.

## Projects

### 1. Ford Car Price Prediction
- **Status:** Trained and tested
- **Algorithm:** Linear Regression
- **Dataset:** [Ford Car Price Prediction on Kaggle](https://www.kaggle.com/datasets/adhurimquku/ford-car-price-prediction)
- **Notebook:** `01-Ford-Car-Price-Prediction/ford_car_price_prediction.ipynb`

The project explores Ford vehicle data and trains a Linear Regression model to predict car prices from vehicle features. Exact evaluation metrics will be added after verifying the notebook's results.

## Getting Started

1. Open the project folder you want to explore.
2. Read its README for dataset and setup instructions.
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Download the dataset from its linked source and update the notebook's data path as needed.
